# Reader

Reader 是一个面向 Windows 的轻量 PDF 阅读与批注、Markdown 阅读与编辑桌面应用，基于 Tauri 2、Rust、React 和 TypeScript。应用代码位于 [`reader/`](reader/)。

## 项目文档

| --- | --- |
| [`AGENTS.md`](AGENTS.md) | 编码代理的工作规则（`CLAUDE.md` 指向同一文件）。 |
| [`docs/STATUS.md`](docs/STATUS.md) | 当前版本、待验收项、已知限制和最新安装包。 |
| [`docs/PRODUCT.md`](docs/PRODUCT.md) | 产品范围和用户可见行为。 |

| [`docs/decisions/`](docs/decisions/) | 长期设计决定及其理由。 |
