# Reader application icon proposals

Local vector candidates following rejection of the solid journal mark on 2026-10-07.

- A: `open-book.svg` — open white pages, muted blue bookmark; recommended direction.
- B: `document-fold.svg` — layered white document and folded corner.
- C: `bookmark-page.svg` — white book/page with slim spine and bookmark.

All three retain transparent outer margins and an opaque paper body. They are original local vector drawings and add no dependency. These are proposals: the generator still reads `../shell-reader.svg`; no candidate has been installed or accepted.

[`preview.png`](preview.png) shows large, 48px desktop, and 24/32px taskbar samples against light, teal and dark backgrounds. The small samples are decoded from the generated ICO frames and drawn at their native pixel sizes. This is an asset proof, not a screenshot or a Windows visual acceptance result. User feedback is recorded in the active icon task.
