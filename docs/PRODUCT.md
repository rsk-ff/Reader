# Product definition

## Purpose

Reader 为 Windows 用户提供一个启动快、界面轻量、同时处理 PDF 与 Markdown 的本地桌面工具。文档内容保留在本机；应用优先复用成熟文档引擎，不重新实现 PDF 排版或 Markdown 语法系统。

本文件定义当前产品应支持的用户可见行为，不证明某项实现已经通过测试或用户验收；实际完成度以 [`STATUS.md`](STATUS.md) 为准。

## Current product contract

### Interface

- 采用中性灰白、深灰正文和克制蓝色强调，通过分区、对齐、分隔线与字号建立层次。工作区与文档行使用直角，交互控件圆角最多 2px，不使用装饰性卡片、浮起动效或阴影。
- 新标签页左侧提供“最近打开”（原“主页”，只列最近文件）、连续排列的固定/常用文件夹，以及最下方的本地磁盘（磁盘图标）和可用的 OneDrive/Dropbox 本机同步目录（两者并列，同属此电脑；此电脑页面也一并列出），没有 Reader 标识、此电脑入口或分组标题。默认桌面/下载/文档/用户目录及用户固定项使用文件夹图标、右侧灰钉；最近常用文件夹接在其后，同样使用文件夹图标但不带钉。“最近打开”主区域直接显示文件列表，顶部不再有标题。新标签页的标签名和图标跟随当前位置：最近打开（时钟）、此电脑（电脑）或当前文件夹名（文件夹，如“桌面”、根目录显示“C:”）。顶部保留后退/前进/上一级/刷新、完整路径地址栏及当前列表筛选（Ctrl+F 聚焦筛选框），没有打开文件或新建按钮。双击磁盘进入目录，根目录上一级可查看磁盘列表；目录列出子文件夹及 PDF/MD/Markdown。仅浏览当前目录，不递归检索，不访问网盘在线 API，不展示推荐或网络映射磁盘。
- OneDrive/Dropbox 自动入口使用云朵图标、不带灰钉；客户端已安装且当前配置的目录可用时才显示，支持个人/工作账户。启动、刷新、切回前台/活动新标签及前台每 30 秒重新识别，卸载客户端隐藏，重装/改路径重新出现；自动项不保存为固定路径。保留本地文件和用户手动固定/历史，自动项与固定/常用同路径时不重复显示；不控制同步或读取账号凭据。
- 右键侧栏或目录中的文件夹可固定/取消固定，默认位置同样可取消并跨启动保留；目录空白处右键可固定当前目录或新建 Markdown。常用文件夹最多 8 项，至少 3 次有效访问才展示：成功打开文件或在活动前台目录连续停留 30 秒计一次，同目录 30 分钟内合并，刷新和快速途经不计。按频率与最近访问权重排序，固定项/磁盘根不重复，90 天未用的不展示；算法与迁移见[决策 0003](decisions/0003-frequent-folders.md)。窄窗口将侧栏变为顶部可滚动导航区。
- 最近文件仍以约 48px 的紧凑行显示名称、位置、打开时间和最近读取的大小，支持路径截断与重新打开；不设记录条数上限，较长列表滚动查看。旧记录未知的时间/大小显示“—”，不推测。目录列表显示修改时间和读取时大小；不可访问目录或文件显示错误，导航仍可恢复。
- PDF 所有工具在顶部一行：左侧是侧栏开关、翻页与页码、缩放和适合宽度/页面；中间是批注工具组（选择、标记、注释、文本框、画笔）；右侧是搜索、打印和保存。高亮、下划线、删除线合并为一个“标记”按钮，点开后在弹出框中选择方式和五种颜色，按钮记住上次的方式和颜色。侧栏顶部用“缩略图/目录”切换（无目录时目录不可选）；在缩略图上右键可在前面或后面插入空白页、删除这一页（只剩一页时不可删）。工具栏从不滚动：窗口放不下时，缩放、搜索、翻页、批注工具依次收进“更多工具”按钮，打印和保存始终可见。
- PDF 与 Markdown 共用右上角的打印/保存控件、名称与状态；窄窗口下这两个控件保持可见。
- PDF 目录/缩略图与 Markdown 目录的最小展开宽度统一为 168px。到最小宽度后继续向左拖过最小宽度的 70%（117.6px），未截断目标宽度达到 50.4px 时完全收起；50.4–168px 区间保持最小展开宽度。通过顶部对应按钮重新展开，恢复本次拖动开始前的宽度；键盘调宽只限制宽度，不触发收起。
- Markdown 保留渲染/源码模式和带标题/数量的目录；格式操作在顶部工具栏，打印和保存在右侧；排版/源码切换（眼睛/代码图标）是文档右下角的悬浮按钮。源码视图左侧显示行号，长行折行时行号对齐该行第一行。选字不显示格式浮层，源码模式禁用渲染格式按钮。格式按钮覆盖正文/六级标题、行内格式、引用、三种列表、代码/公式块、表格、图片及分隔线；工具栏从不滚动：窗口放不下时，插入、段落、搜索、文字格式依次收进“更多工具”按钮，打印和保存始终可见。所有滚动条统一为无箭头的细圆角样式。官方 Frame 为正文基线，引用与代码/公式块采用紧凑间距。
- 软件 Logo 是 Fluent 风格的金色银杏叶（渐变、高光、轻投影，无底板），用于窗口、任务栏、安装包和网页图标。Windows 中关联的 `.pdf`、`.md`/`.markdown` 文件图标是无折角的白色纸页，正中一片银杏，下方居中一块带类型字样的色签（PDF 红、MD 蓝）；16/20/24px 小图标是逐像素绘制的版本（纸页加像素字 PDF/MD 色签，不画银杏，布局与大图标一致），保证资源管理器小图标和详细信息视图清晰。标题栏不显示软件图标，标签从最左侧开始。界面图标统一使用 Lucide 线性图标（18px、1.6px 圆头描边）。软件内的 PDF/Markdown 文件图标是 Lucide 折角纸张轮廓，下方窄色条区分类型，颜色与 Windows 文件图标一致（PDF `#b85454`、Markdown `#5579ab`）。PDF 与 Markdown 工具栏左端的侧栏开关和分隔线、右端从搜索到保存使用同一组件，位置和尺寸一致。保存按钮是图标，有未保存更改时右上角显示圆点。激活标签通过背景与边界区分，无底部强调线。
- 控件提供键盘焦点反馈；减少动画偏好停用界面过渡。标题栏与原生窗口控件保留固定几何尺寸。
- 新标签页文件夹浏览支持鼠标侧键返回/前进，与顶部按钮共用每标签的导航历史；到历史边界不跳转，只有活动新标签响应，打开文件或新建对话框期间暂不导航。
- 从新标签页（目录列表或最近打开）打开文件后 10 秒内，只要文件还没有任何改动（PDF 批注、改页或 Markdown 编辑，保存过也算），按鼠标后退侧键即把该标签还原为新标签页：回到打开前的文件夹和前进/后退历史，刚才的文件保持选中，最近打开撤销这次记录。右键文件选“在新标签页中打开”时，文件在新标签页右侧单独开一个标签并切过去，新标签页保留原位置；10 秒内且未改动时按侧键会关闭这个文件标签并切回新标签页。超时、已改动、切换到其他标签（切回来也不行）或标签被拖到其他窗口后，侧键不做任何事；切到其他软件再回来不影响；文件本已在同一窗口的其他标签打开时会直接跳到那个标签、新标签页保持不动，此时同样在 10 秒内且跳转后未改动、未切走时，按侧键切回那个新标签页。

### PDF

- 打开、拖入或通过文件关联启动 `.pdf` 文件。
- 连续阅读、缩放、搜索、复制文本、使用目录和缩略图导航；目录按层级逐行显示，并忽略由生成工具写入的空白页占位书签。
- 可从文字行左右的页面空白处按住拖入文字建立选区，支持反向和跨行选择；单击空白处取消选区。
- 向下拖到末行下方空白时，选区包含该行剩余文字；反向拖到首行上方时包含该行开头。拖回文字上恢复精确字符终点，释放后不再随鼠标移动调整。
- 已有文字选区在按钮、快捷键、Ctrl＋滚轮及适合页面/宽度缩放时保留相同内容和方向；连续滚轮和页面重绘期间选中文字仍可复制。搜索高亮重绘不使选区失效，用户取消后不恢复旧选区。
- 打印文档（见下方“打印”）。
- 新建高亮、下划线、删除线、便笺、自由文本和墨迹批注。
- 删除应用支持的批注，插入空白页和删除页面。
- 批注、插页和删页先写入私有工作副本，原文件保持不变；点保存或 Ctrl+S 才写回原文件，关闭有未保存更改的 PDF 时提示保存、不保存或取消。
- 高亮、下划线和删除线按 Acrobat/PDF.js 的四角顺序（左上、右上、左下、右下）写入，在其他阅读器中下划线位于文字下方；高亮半透明，下划线和删除线为不透明线条。
- 删页使用应用内模态确认，默认聚焦取消，Esc 取消，并提示点保存后才写入文件；最后一页不能删除。

### Markdown

- 打开、拖入或通过文件关联启动 `.md` 与 `.markdown` 文件。
- 在新标签页浏览目录，右键空白处选择“新建 Markdown”，输入文件名后直接在当前目录创建并打开；无扩展名时补 `.md`，已有文件不能覆盖，取消不创建文件。
- 在所见即所得和源码模式之间切换。
- 所见即所得连续编辑时保持光标、选区和本次编辑的撤销历史；重复点击当前模式不重置编辑器。切换源码/所见即所得会重新加载内容，暂不跨模式保留撤销历史。
- 在可见区域内选中文字或取消选区时，正文排版和滚动位置保持稳定。
- 所见即所得区域使用 Crepe 官方 Frame 浅色主题统一正文和编辑控件，适配本地中英文字体与等宽代码字体。
- 标题只在 H1–H3 保留字号梯度（正文 16px 时为 28/24/20px），H4–H6 使用正文大小的粗体；保留六级标题语义和目录。正文不提供左侧块加号/点阵拖动及附属斜杠块菜单，保留普通 Markdown 输入、选中文本格式工具和代码折叠。
- 保存和切换源码前同步读取实时内容，防止延迟监听漏掉刚输入或插入的内容；保存仍使用版本保护。
- 插入本地图片时以内嵌 data URL 保存到 Markdown，避免临时 blob 地址随关闭失效；图片会增加文件大小。
- 文档里引用的本地图片（相对 .md 的路径、绝对路径或 `file:` 地址）会直接显示，范围限于 .md 所在文件夹及其子文件夹；`https` 网络图片也直接加载。
- 引用竖线与文字相隔 12px；代码/公式工具区始终可见且紧凑，正文和公式预览区上下均使用 12px 内边距。
- 显式保存，并正确显示未保存状态。
- 顶部工具栏右侧有文档搜索（不区分大小写，可跨粗体等格式）：输入后按回车才开始搜索（与 PDF 一致），Ctrl+F 聚焦，再按回车/F3 下一个，Shift+回车/Shift+F3 上一个，Esc 清空。排版与源码视图都高亮全部匹配，当前匹配颜色更深并滚动到可见；编辑时不会自动跳转。
- 顶部按钮与 Ctrl+P 打开打印窗口，打印点击时的完整内容（包括未保存编辑）；源码模式同样输出渲染排版，打印不切换模式、写入文件或重置活动编辑器。
- 使用左侧目录浏览标题并跳转；拖动目录右边缘调整宽度（168–560px，窄窗口自动限制上限但保留最小展开宽度）。顶部目录开关可完全收起/展开，正文占用释放的空间；同一标签页恢复先前宽度，源码/渲染模式切换保留宽度和收起状态，重开文档恢复默认布局。

### 打印

- PDF 与 Markdown 的打印按钮和 Ctrl+P 打开 Reader 自己的打印窗口（应用内模态，Esc 取消；下拉列表打开时 Esc 只收起列表）。样式与其他弹窗一致：界面字体、13px 正文、15px 标题，控件为软件自绘的下拉框、复选框和分段按钮。
- 左侧是当前一张纸的预览，顶部可前后翻看并显示“第 N 张 / 共 M 张”和纸张、方向；底部是全部页面的缩略图条，不打印的页变淡，当前这张纸上的页加框，点击跳到所在的那张纸。
- 右侧选项：打印机（系统列表，默认打印机标“默认”）；份数（1–999，多于 1 份时可选逐份打印）；页面（全部 / 当前页 / 自定义，例如 `1-5, 8`、`10-`，越界或格式错误时提示并禁止打印；Markdown 没有“当前页”）；纸张（打印机支持的尺寸）；方向（PDF：自动/纵向/横向，自动按首个要打印的页面决定；Markdown：纵向/横向）；每张页数（1/2/4/6/9/16，按阅读顺序排，页间留 4mm）；PDF 缩放（适合纸张/实际大小，每张多页时固定为适合）；Markdown 页边距（窄 10mm/正常 18mm/宽 25mm）；双面（单面/长边翻转/短边翻转，打印机不支持时不显示）；颜色（彩色/黑白，预览同步变灰，黑白打印机不显示）；PDF 的“打印批注”（默认勾选）；“打印机属性…”打开驱动自己的设置，确定后纸张、方向、双面、颜色、份数同步回窗口。
- 适合纸张时页面缩放到打印机的可打印区域内居中；页面方向与格子不符且转 90° 能放得更大时自动旋转。
- 底部显示本次用纸张数（含份数与双面）；打印交给系统后关闭窗口，失败时在底部显示原因。
- PDF 打印当前内容，包括未保存的批注和增删页；Markdown 按所选纸张、方向和页边距重新分页，预览即实际分页。
- 记住上次的打印机、各打印机的纸张与驱动设置、方向、每张页数、缩放、双面、颜色、逐份、批注和页边距；份数和页面范围每次重置。

### Windows shell

- 在一个或多个原生窗口中使用标签页。
- 无文件启动时显示“新标签页”；点击标签栏右侧加号可继续新增并聚焦新标签页，关闭主窗口最后一个标签后自动补回新标签页。
- 新标签页通过侧栏与目录列表查找本地文件；主页显示跨普通启动保留的最近文件。主区域的文件、文件夹和磁盘与资源管理器一致：单击只选中，双击或回车才打开文件、进入文件夹；左侧导航栏仍是单击切换。显示主页时在后台逐个检查最近文件是否还在（不在启动时检查，慢速或离线的盘不会卡住界面）；确定已不存在的文件变灰并标“已不存在”，不会自动删除。打开失败时弹窗说明原因；最近文件已不存在时弹窗可选择“从列表中移除”。固定和常用位置仅在导航中连续排列。
- 新标签页本身不绑定文件；打开已有文件或在目录中新建 Markdown 后直接复用活动新标签槽位，带文件参数启动不额外创建空标签。
- 切换、关闭、重排、拖出和跨窗口停靠标签页。
- 标签页显示 PDF、Markdown 或通用文件类型图标；同一标签栏中的标签页等宽，并在 `28px` 至 `220px` 范围内随可用标题栏空间自适应。空间收缩时先隐藏未选中标签的关闭按钮，文字自然被截断；极窄时选中标签保留关闭按钮，未选中标签保留类型图标。
- 在 Windows 资源管理器中通过 Reader 关联后，`.pdf` 使用 PDF 专用图标，`.md` 与 `.markdown` 使用 Markdown 专用图标。
- 跨窗口拖动时，指针进入可见标签页栏会抬升对应窗口；随指针移动的标签或单标签来源窗口始终显示在目标之上，返回来源标签页栏时来源窗口可重新上浮。
- 在只有一个标签时通过标签区域拖动整个窗口。
- 使用 Windows 原生最小化、最大化、关闭和 Snap Layout 行为。
- 保存会话元数据供退出和潜在恢复使用；普通启动不自动恢复上次文档。

## Product principles

- 本地优先：阅读、编辑和文档写入不依赖在线账户或云服务。
- 数据完整性优先于便利性：存在未保存 Markdown 时，不执行可能丢失编辑内容的跨窗口移动。
- 轻量优先：复用成熟文档引擎，避免维护重复的排版和渲染栈。
- 优先解决阻断阅读、编辑、保存和窗口操作的问题，再扩充次要功能。

## Current non-goals

- 云同步、多人协作和在线账户系统。
- 用自研引擎替代 PDF.js、PDFium 或 Milkdown。
- 为未保存 Markdown 提供崩溃恢复或跨 webview 状态迁移。
- 在当前阶段承诺 Windows 之外的平台发布。
