# Product definition

## Purpose

Reader 为 Windows 用户提供一个启动快、界面轻量、同时处理 PDF 与 Markdown 的本地桌面工具。文档内容保留在本机；应用优先复用成熟文档引擎，不重新实现 PDF 排版或 Markdown 语法系统。

本文件定义当前产品应支持的用户可见行为，不证明某项实现已经通过测试或用户验收；实际完成度以 [`STATUS.md`](STATUS.md) 为准。

## Current product contract

### Interface

- 采用中性灰白、深灰正文和克制蓝色强调，通过分区、对齐、分隔线与字号建立层次。工作区与文档行使用直角，交互控件圆角最多 2px，不使用装饰性卡片、浮起动效或阴影。
- 首页仅保留软件名称、文件操作与最近文档：宽窗口左右排列，窄窗口上下排列；最近文档以约 48px 的紧凑行显示名称、位置、打开时间和最近读取的大小，支持路径截断与重新打开；不设记录条数上限，较长列表滚动查看。旧记录未知的时间/大小显示“—”，不推测。
- PDF 顶部仅保留一行阅读导航、缩放和搜索；标注、插页与删页使用右侧竖栏。顶部阅读控件在窄窗口可横向滚动，右侧工具可纵向滚动。
- PDF 与 Markdown 共用右上角的打印/保存控件、名称与状态；窄窗口下这两个控件保持可见。
- Markdown 保留渲染/源码模式和带标题/数量的目录；文本格式操作放到右侧竖栏，选字不显示格式浮层，源码模式禁用渲染格式按钮。使用统一 Bootstrap 图标，覆盖正文/六级标题、行内格式、引用、三种列表、代码/公式块、表格、图片及分隔线；短窗口可滚动工具栏。官方 Frame 为正文基线，引用与代码/公式块采用紧凑间距。
- 软件与 PDF/Markdown 文件在软件内部和 Windows 使用同一套 SVG 母版：软件采用带白色纸页、蓝色封面及明暗层次的 Microsoft Fluent 书本；PDF/MD 保留之前 Bootstrap 纸张轮廓与字形，纸面不透明白色，红/蓝格式底配白字与窄白边，外围透明；未知类型采用中性纸面。标题栏、首页、标签、最近记录、拖拽预览和系统图标保持一致，各位置只调整显示尺寸。PDF/Markdown 右侧工具共用 Bootstrap SVG 遮罩、18px 图形及按钮样式，删除线共用同一图形。激活标签通过背景与边界区分，无底部强调线。
- 文件左下角格式标识借鉴 Word：PDF 红底白字、MD 蓝底白字，外围窄白边与纸面分开；标签保留紧凑尺寸，最近列表以较大图形匹配两行文字，行高仍约 48px；Windows 文件图标减少外围留白，软件书本图标保持已认可版本。
- 控件提供键盘焦点反馈；减少动画偏好停用界面过渡。标题栏与原生窗口控件保留固定几何尺寸。

### PDF

- 打开、拖入或通过文件关联启动 `.pdf` 文件。
- 连续阅读、缩放、搜索、复制文本、使用目录和缩略图导航；目录按层级逐行显示，并忽略由生成工具写入的空白页占位书签。
- 可从文字行左右的页面空白处按住拖入文字建立选区，支持反向和跨行选择；单击空白处取消选区。
- 向下拖到末行下方空白时，选区包含该行剩余文字；反向拖到首行上方时包含该行开头。拖回文字上恢复精确字符终点，释放后不再随鼠标移动调整。
- 已有文字选区在按钮、快捷键、Ctrl＋滚轮及适合页面/宽度缩放时保留相同内容和方向；连续滚轮和页面重绘期间选中文字仍可复制。搜索高亮重绘不使选区失效，用户取消后不恢复旧选区。
- 打印文档。
- 新建高亮、下划线、删除线、便笺、自由文本和墨迹批注。
- 删除应用支持的批注，插入空白页和删除页面。
- 删页使用应用内模态确认，默认聚焦取消，Esc 取消；明确提示修改立即写入文件，最后一页不能删除。

### Markdown

- 打开、拖入或通过文件关联启动 `.md` 与 `.markdown` 文件。
- 可从新标签页直接创建未命名 Markdown；新建时不选择位置，首次保存时再通过原生对话框确定路径。
- 在所见即所得和源码模式之间切换。
- 所见即所得连续编辑时保持光标、选区和本次编辑的撤销历史；重复点击当前模式不重置编辑器。切换源码/所见即所得会重新加载内容，暂不跨模式保留撤销历史。
- 在可见区域内选中文字或取消选区时，正文排版和滚动位置保持稳定。
- 所见即所得区域使用 Crepe 官方 Frame 浅色主题统一正文和编辑控件，适配本地中英文字体与等宽代码字体。
- 标题只在 H1–H3 保留字号梯度（正文 16px 时为 28/24/20px），H4–H6 使用正文大小的粗体；保留六级标题语义和目录。正文不提供左侧块加号/点阵拖动及附属斜杠块菜单，保留普通 Markdown 输入、选中文本格式工具和代码折叠。
- 保存和切换源码前同步读取实时内容，防止延迟监听漏掉刚输入或插入的内容；保存仍使用版本保护。
- 插入本地图片时以内嵌 data URL 保存到 Markdown，避免临时 blob 地址随关闭失效；图片会增加文件大小。
- 引用竖线与文字相隔 12px；代码/公式工具区始终可见且紧凑，正文和公式预览区上下均使用 12px 内边距。
- 显式保存，并正确显示未保存状态。
- 支持顶部按钮与 Ctrl+P 打印点击时的完整内容（包括未保存编辑）；源码模式同样输出渲染排版，打印不切换模式、写入文件或重置活动编辑器。
- 使用左侧目录浏览标题并跳转。

### Windows shell

- 在一个或多个原生窗口中使用标签页。
- 无文件启动时显示“新标签页”；点击标签栏右侧加号可继续新增并聚焦新标签页，关闭主窗口最后一个标签后自动补回新标签页。
- 新标签页提供“打开文件”和“新建 Markdown”入口，下方显示跨普通启动保留的最近文件；点击最近文件可重新打开。
- 新标签页本身不绑定文件；打开文件或创建未命名 Markdown 时直接复用活动新标签槽位，带文件参数启动不额外创建空标签。
- 切换、关闭、重排、拖出和跨窗口停靠标签页。
- 标签页显示 PDF、Markdown 或通用文件类型图标；同一标签栏中的标签页等宽，并在 `28px` 至 `220px` 范围内随可用标题栏空间自适应。空间收缩时先隐藏未选中标签的关闭按钮，文字自然被截断；极窄时选中标签保留关闭按钮，未选中标签保留类型图标。
- 在 Windows 资源管理器中通过 Reader 关联后，`.pdf` 使用 PDF 专用图标，`.md` 与 `.markdown` 使用 Markdown 专用图标。
- 跨窗口拖动时，指针进入可见标签页栏会抬升对应窗口；随指针移动的标签或单标签来源窗口始终显示在目标之上，返回来源标签页栏时来源窗口可重新上浮。
- 在只有一个标签时通过标签区域拖动整个窗口。
- 使用 Windows 原生最小化、最大化、关闭和 Snap Layout 行为。
- 保存会话元数据供退出和潜在恢复使用；普通启动不自动恢复上次文档。

## Product principles

- 本地优先：阅读、编辑和文档写入不依赖在线账户或云服务。
- 数据完整性优先于便利性：存在未保存 Markdown 时，不执行可能丢失编辑内容的跨窗口移动。
- 轻量优先：复用成熟文档引擎，避免维护重复的排版和渲染栈。
- 优先解决阻断阅读、编辑、保存和窗口操作的问题，再扩充次要功能。

## Current non-goals

- 云同步、多人协作和在线账户系统。
- 用自研引擎替代 PDF.js、PDFium 或 Milkdown。
- 为未保存 Markdown 提供崩溃恢复或跨 webview 状态迁移。
- 在当前阶段承诺 Windows 之外的平台发布。
