# Product definition

## Purpose

Reader 为 Windows 用户提供一个启动快、界面轻量、同时处理 PDF 与 Markdown 的本地桌面工具。文档内容保留在本机；应用优先复用成熟文档引擎，不重新实现 PDF 排版或 Markdown 语法系统。

本文件定义当前产品应支持的用户可见行为，不证明某项实现已经通过测试或用户验收；实际完成度以 [`STATUS.md`](STATUS.md) 为准。

## Current product contract

### PDF

- 打开、拖入或通过文件关联启动 `.pdf` 文件。
- 连续阅读、缩放、搜索、复制文本、使用目录和缩略图导航；目录按层级逐行显示，并忽略由生成工具写入的空白页占位书签。
- 打印文档。
- 新建高亮、下划线、删除线、便笺、自由文本和墨迹批注。
- 删除应用支持的批注，插入空白页和删除页面。

### Markdown

- 打开、拖入或通过文件关联启动 `.md` 与 `.markdown` 文件。
- 可从新标签页直接创建未命名 Markdown；新建时不选择位置，首次保存时再通过原生对话框确定路径。
- 在所见即所得和源码模式之间切换。
- 显式保存，并正确显示未保存状态。
- 使用左侧目录浏览标题并跳转。

### Windows shell

- 在一个或多个原生窗口中使用标签页。
- 无文件启动时显示“新标签页”；点击标签栏右侧加号可继续新增并聚焦新标签页，关闭主窗口最后一个标签后自动补回新标签页。
- 新标签页提供“打开文件”和“新建 md”入口，下方显示跨普通启动保留的最近文件；点击最近文件可重新打开。
- 新标签页本身不绑定文件；打开文件或创建未命名 Markdown 时直接复用活动新标签槽位，带文件参数启动不额外创建空标签。
- 切换、关闭、重排、拖出和跨窗口停靠标签页。
- 标签页显示 PDF、Markdown 或通用文件类型图标；同一标签栏中的标签页等宽，并在 `28px` 至 `220px` 范围内随可用标题栏空间自适应。空间收缩时先隐藏未选中标签的关闭按钮，文字自然被截断；极窄时选中标签保留关闭按钮，未选中标签保留类型图标。
- 在 Windows 资源管理器中通过 Reader 关联后，`.pdf` 使用 PDF 专用图标，`.md` 与 `.markdown` 使用 Markdown 专用图标。
- 跨窗口拖动时，指针进入可见标签页栏会抬升对应窗口；随指针移动的标签或单标签来源窗口始终显示在目标之上，返回来源标签页栏时来源窗口可重新上浮。
- 在只有一个标签时通过标签区域拖动整个窗口。
- 使用 Windows 原生最小化、最大化、关闭和 Snap Layout 行为。
- 保存会话元数据供退出和潜在恢复使用；普通启动不自动恢复上次文档。

## Product principles

- 本地优先：阅读、编辑和文档写入不依赖在线账户或云服务。
- 数据完整性优先于便利性：存在未保存 Markdown 时，不执行可能丢失编辑内容的跨窗口移动。
- 轻量优先：复用成熟文档引擎，避免维护重复的排版和渲染栈。
- 优先解决阻断阅读、编辑、保存和窗口操作的问题，再扩充次要功能。

## Current non-goals

- 云同步、多人协作和在线账户系统。
- 用自研引擎替代 PDF.js、PDFium 或 Milkdown。
- 为未保存 Markdown 提供崩溃恢复或跨 webview 状态迁移。
- 在当前阶段承诺 Windows 之外的平台发布。
